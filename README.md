# projetos_ppdm

# Últimos Exercícios Implementados

Neste projeto foram adicionadas quatro melhorias no cartão de identificação estudantil:

## 1. Imagem real no CircleAvatar

O ícone padrão do perfil foi substituído por uma imagem real utilizando o widget `NetworkImage` dentro do `CircleAvatar`, permitindo carregar uma foto através de uma URL.

## 2. Seção "Sobre Mim"

Foi criada uma nova área chamada **"Sobre Mim"**, contendo uma breve biografia do estudante apresentada no cartão.

## 3. Badges de habilidades com Chip

Foram adicionadas habilidades utilizando o widget `Chip`, organizadas dentro de uma `Row`, exibindo tecnologias como Flutter, Dart e Firebase.

## 4. Fundo com gradiente

O fundo do cartão foi personalizado utilizando `LinearGradient` dentro da decoração do `Container`, criando um efeito visual com transição de cores.

Essas alterações tiveram como objetivo praticar a utilização de widgets do Flutter, personalização de layouts e organização de componentes de interface.
